# 🚀 The "Ops" Alphabet Soup — Part 2

## The Engineering Toolkit Behind Every "Ops"

Part 1 covered **what each "Ops" discipline means.**

Now let's answer the question every engineer eventually asks:

> **"If I'm working in this space, what tools should I know?"**

Here's a practical, multi-cloud reference guide. 👇

| **Ops**                     | **Primary Mission**                                        | **Core Enterprise Tooling**                                                                   |

## 🧩 How These Disciplines Fit Together

They're **not competing practices**—they're complementary layers of a modern engineering platform.

* **DevOps** → Accelerates software delivery
* **DevSecOps** → Makes delivery secure by default
* **GitOps** → Makes deployments declarative and auditable
* **Platform Engineering** → Improves the developer experience
* **DataOps** → Delivers trusted, production-ready data
* **MLOps** → Operationalizes machine learning
* **LLMOps & AgentOps** → Bring GenAI and autonomous agents into production
* **FinOps** → Keeps cloud costs sustainable
* **AIOps** → Reduces operational noise with intelligence
* **ITOps / NetOps** → Keeps infrastructure running
* **ChatOps** → Brings operations into collaboration workflows
* **TestOps** → Ensures quality at scale
* **SRE** → Maintains reliability through observability and engineering discipline
